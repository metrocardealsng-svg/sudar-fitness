Sudar Fitness Shorts Uploader (YouTube API Services)

The tool uses YouTube API Services and is used only by Sudar Fitness on its own channel. It requests permission to upload videos and read our channel's video list. It does not collect, store, or share data about other YouTube users. By using it you agree to the YouTube Terms of Service; see also the Google Privacy Policy. Access can be revoked at any time at myaccount.google.com/permissions.

Data storage and deletion

The tool does not store any YouTube API data. Titles of our own recent videos are read during each run only to avoid repeating a topic, and are discarded when the run ends. Uploaded videos can be deleted at any time in YouTube Studio. To ask us to delete any data we hold about you, email peaceinnocent2002@gmail.com and we will do so within 7 days.
